# 速查挑战 · 25 题

**规则：每题一条命令解决（可以带管道），思考时间 30 秒。** 不查手册、不翻本库文档，凭手感写。

> 用途：检验"常用命令是否已经变成反射"。写不出来说明那个命令你只在"看懂"层面，没有"能写出来"。
>
> 答案通常是**一种**写法。你的写法若输出一致，算对。答案里会顺带点出该命令最容易错的地方。

## 一、文件与目录（1–6）

### 挑战 1 · 列出当前目录下**最大的 10 个文件**

<details><summary>答案（20 秒内应该能写出）</summary>

```bash
$ du -ah . 2>/dev/null | sort -h | tail -10
```

或者用 `find` 更精确（只统计普通文件）：

```bash
$ find . -type f -printf '%s %p\n' | sort -n | tail -10
```

**要点**：
- `du` 默认统计**目录的总和**，`-a` 才会列出每个文件。
- **必须用 `sort -h`**（human-numeric），否则 `1.2G` 会排在 `3.5M` 前面。
- `find -printf '%s'` 输出的是**字节数**（可以直接 `sort -n`，不用 `-h`）。
- 加 `-xdev` 避免跨文件系统（在 `/` 下跑时很重要）。

</details>

### 挑战 2 · 找出当前目录下**3 天内修改过**的所有 `.py` 文件

<details><summary>答案</summary>

```bash
$ find . -type f -name '*.py' -mtime -3
```

**要点**：
- `-mtime -3` 是"**小于** 3 天"。写成 `-mtime 3` 是"3~4 天前那个区间"，是新手最常见的错误。
- 想按精确时间：`-newermt '-3 days'`。
- 想看**修改时间**而不只是文件名：`-printf '%TY-%Tm-%Td %TH:%TM %p\n'`。

</details>

### 挑战 3 · 统计当前目录有多少个文件（不递归子目录）

<details><summary>答案</summary>

```bash
$ find . -maxdepth 1 -type f | wc -l
```

**要点**：
- `ls -1 | wc -l` 也能用，但它会**把每个子目录算成一项**（即使你只要文件），而且文件名含换行时会数错。
- `-maxdepth 1` 与 `-mindepth 1` 一起用时可以排除 `.` 自身。
- 要**同时**统计文件与目录：`ls -A | wc -l`。

</details>

### 挑战 4 · 创建一个带时间戳的备份目录

<details><summary>答案</summary>

```bash
$ mkdir -p "backup/$(date +%Y%m%d-%H%M%S)"
```

**要点**：
- **必须加引号** `"$(...)"`。不加引号时如果 `date` 的输出含空格（自定义格式时容易发生），会被拆成多个参数。
- `mkdir -p` 保证父目录存在、且重名不报错。
- 常用格式：`%Y%m%d`（20260915，可排序）、`%s`（Unix 时间戳，绝对唯一）、`%F`（2026-09-15）。

</details>

### 挑战 5 · 把 `a.txt` 变成 `a.txt.bak`（原地改名）

<details><summary>答案</summary>

```bash
$ mv a.txt a.txt.bak
# 或者用花括号展开一次处理多个
$ mv a.txt{,.bak}
```

**要点**：
- `{,.bak}` 展开成 `"" ".bak"` 两个词，于是命令变成 `mv a.txt a.txt.bak`。这是改名的省事写法。
- 批量改名（加时间戳后缀）：`for f in *.txt; do mv -- "$f" "$f.$(date +%F)"; done`。

</details>

### 挑战 6 · 查看一个文件"实际占了多少磁盘块"（而不是逻辑大小）

<details><summary>答案</summary>

```bash
$ du -h file
4.0K    file
$ stat -c '%s 逻辑字节  %b 个512字节块' file
```

**要点**：
- 文件系统按**块**分配，一个 1 字节的文件也占 4K（典型的 4K 块）。
- `du -h` 显示实际占用；`ls -l` / `stat -c %s` 显示**逻辑大小**。
- **稀疏文件**两者差异巨大：`truncate -s 1G sparse` 创建的 1G 文件，`du` 显示 0。

</details>

## 二、文本处理（7–14）

### 挑战 7 · 统计一个文件有多少行

<details><summary>答案</summary>

```bash
$ wc -l file
$ wc -l < file          # 只要数字（脚本里用）
```

**要点**：
- `wc -l` 数的是**换行符**个数。文件最后一行没有换行符时会被漏数。
- `<` 让 `wc` 从 stdin 读，输出就只有数字，方便赋值给变量。

</details>

### 挑战 8 · 打印一个文件的第 100 到 120 行

<details><summary>答案</summary>

```bash
$ sed -n '100,120p' file
```

**要点**：
- **`-n` 必须有**。不加 `-n` 时 sed 会先把所有行打印一遍，再把 100–120 行重复打印一遍。
- 等价写法：`awk 'NR>=100 && NR<=120' file`。
- 从第 100 行到末尾：`sed -n '100,$p' file`。

</details>

### 挑战 9 · 把文件里所有 `foo` 换成 `bar`（不改原文件，只输出）

<details><summary>答案</summary>

```bash
$ sed 's/foo/bar/g' file
```

**要点**：
- `g` 不能少。不加 `g` 只替换每行的**第一个**匹配。
- 想改原文件：`sed -i 's/foo/bar/g' file`（BSD/macOS 要写 `sed -i '' 's/.../../'`）。
- **想先确认再改**：`sed 's/foo/bar/g' file | diff file -`。

</details>

### 挑战 10 · 找出一个文件里所有**重复出现**的行（出现 ≥2 次）

<details><summary>答案</summary>

```bash
$ sort file | uniq -d
```

**要点**：
- **`sort` 不能省**。`uniq` 只合并**相邻**的重复行，未排序的文件里相同内容不相邻，`uniq` 看不到。
- 想同时看次数：`sort file | uniq -c | sort -rn`。
- 想只看"唯一出现一次"的：`uniq -u`。

</details>

### 挑战 11 · 提取一个文件里所有 IP 地址

<details><summary>答案</summary>

```bash
$ grep -oE '([0-9]{1,3}\.){3}[0-9]{1,3}' file
```

**要点**：
- `-o` 只输出匹配的部分（一行有多个匹配会输出多行）。
- `-E` 用扩展正则，`{n}` 和 `|` 才不需要转义。
- **这个正则不校验每段 ≤ 255**，`999.999.999.999` 也会被匹配。严格校验需要更复杂的模式。

</details>

### 挑战 12 · 累加一列数字（比如每行第一个字段）

<details><summary>答案</summary>

```bash
$ awk '{s += $1} END {print s}' file
```

**要点**：
- `END` 块在处理完所有行后执行一次，是聚合计算的正确位置。
- awk 的数字都是**双精度浮点**，金额计算会有精度问题（用 `bc` 或 `python3`）。
- 空行会让 `$1` 为空，`s += ""` 被当成 0，不会报错但也不影响结果。

</details>

### 挑战 13 · 按第 2 列**数值**降序排序

<details><summary>答案</summary>

```bash
$ sort -k2,2nr file
```

**要点**：
- `-k2,2` 明确"排序键从第 2 字段到第 2 字段"。省略结束位置（`-k2nr`）时排序键会延伸到行尾，多列时结果不同。
- `n` 按数值（不加则是字典序，`10` 会排在 `9` 前面）。
- `r` 降序。
- ⚠️ **`sort file > file` 会把文件清空**（`>` 在 sort 读之前就截断了）。用 `sort -o file file`。

</details>

### 挑战 14 · 只看 `ps aux` 输出里的 `USER` 列并去重计数

<details><summary>答案</summary>

```bash
$ ps aux | awk 'NR>1 {print $1}' | sort | uniq -c | sort -rn
```

**要点**：
- `NR>1` 跳过表头（`ps aux` 第一行是 `USER PID ...`）。
- `sort | uniq -c | sort -rn` 是"统计频次并排序"的固定三连。
- 也可以用 `ps -eo user= | sort | uniq -c`（`=` 后缀表示不要表头）。

</details>

## 三、权限与用户（15–18）

### 挑战 15 · 找出系统上所有 SUID 文件

<details><summary>答案</summary>

```bash
$ sudo find / -xdev -type f -perm -4000 -exec ls -l {} + 2>/dev/null
```

**要点**：
- **`-perm -4000`（带短横线）** = "包含 SUID 位"。写成 `-perm 4000` 是"权限位精确等于 4000"，几乎匹配不到东西。
- `-xdev` 不跨文件系统，避免扫 `/proc`、网络盘，又快又安全 🔐。
- `-type f` 只要普通文件（SUID 对目录和软链接无意义）。

</details>

### 挑战 16 · 把文件权限设成"只有属主能读写"

<details><summary>答案</summary>

```bash
$ chmod 600 file
```

**要点**：
- `6` = `rw-`（属主），两个 `0` = 属组和其他人无任何权限。
- 对比：`644` 世界可读，`640` 属组可读。
- 私钥、含密码的配置、脚本应当是 `600`。

</details>

### 挑战 17 · 查看当前用户属于哪些组

<details><summary>答案</summary>

```bash
$ id -nG
rivo adm cdrom sudo audio video docker
$ groups
```

**要点**：
- `id -nG`（`-n` 显示名字，`-G` 显示所有组）比 `groups` 更适合脚本。
- `id -Gn $(whoami)` 也可以，但多此一举。
- **注意**：新加入的组要**重新登录**（或 `newgrp <组>`）才在会话里生效。

</details>

### 挑战 18 · 查看某人能用 `sudo` 执行哪些命令

<details><summary>答案</summary>

```bash
$ sudo -l -U alice
```

**要点**：
- 不带 `-U` 时查的是**自己**。
- 输出里的 `(ALL : ALL) ALL` 表示完全 root 等价。
- 🔐 这是拿到低权限 shell 后的**第一步**：任何允许的命令，只要它能"执行任意程序"或"读写任意文件"，就等于 root（GTFOBins 清单）。

</details>

## 四、进程与系统（19–22）

### 挑战 19 · 找出占用 8080 端口的进程

<details><summary>答案</summary>

```bash
$ sudo ss -tlnp 'sport = :8080'
```

**要点**：
- `-p` 显示进程（不加就只看到端口在监听）。
- `sport = :8080` 是 `ss` 自带的过滤语法，比 `| grep 8080` 精确（`grep 8080` 会匹配到客户端端口是 8080 的连接）。
- 替代：`sudo lsof -i :8080`、`sudo fuser 8080/tcp`。

</details>

### 挑战 20 · 优雅地停止一个进程（不用 `kill -9`）

<details><summary>答案</summary>

```bash
$ kill <PID>
# 或者按名字
$ pkill -x myapp
```

**要点**：
- `kill` 默认发 **SIGTERM(15)**，进程可以保存数据、清理后再退出。
- `kill -9` 是 SIGKILL，**不可捕获**，会丢数据、留下锁文件。
- 正确顺序：`kill` → 等几秒 → 还在才 `kill -9`。
- 判断是否还活着：`kill -0 <PID> 2>/dev/null`。

</details>

### 挑战 21 · 让一个命令最多跑 10 秒

<details><summary>答案</summary>

```bash
$ timeout 10 some_command
```

**要点**：
- 超时时退出码是 **124**（可以据此判断）。
- 超时后还想给宽限期再强杀：`timeout -k 5 10 cmd`（10 秒后发 TERM，再等 5 秒发 KILL）。
- **只它自己启动的进程**，不连带杀子进程；要连带用 `setsid` 包一层。

</details>

### 挑战 22 · 查看系统最近一次启动的所有错误日志

<details><summary>答案</summary>

```bash
$ journalctl -b -p err --no-pager
```

**要点**：
- `-b` 只看**本次启动**；`-b -1` 是上一次启动。
- **`-p err` 表示"err 及以上"**（warning 下的都能出来），不是"只有 err"。
- `--no-pager` 避免输出被 less 接管（脚本/复制时必加）。
- 想只看某个服务：`journalctl -u nginx -b -p err`。

</details>

## 五、网络（23–25）

### 挑战 23 · 查看本机所有对外监听的端口

<details><summary>答案</summary>

```bash
$ sudo ss -tulnp | grep -vE '127\.0\.0\.1|\[::1\]'
```

**要点**：
- `-t` TCP，`-u` UDP，`-l` 监听，`-n` 不解析名称，`-p` 显示进程。
- **过滤掉 `127.0.0.1` 才是"真正对外暴露"的** —— 这是暴露面审计的核心动作 🔐。
- 只监听 TCP 的话 `-tl` 就够，`-u` 会额外显示 DNS、DHCP 等 UDP 服务。

</details>

### 挑战 24 · 只取一个 HTTP 请求的状态码

<details><summary>答案</summary>

```bash
$ curl -sS -o /dev/null -w '%{http_code}\n' https://example.com
```

**要点**：
- **`-o /dev/null` 不能少**。不加的话响应体会打到屏幕上，状态码混在最后。
- `-w '%{http_code}\n'` 里的 `\n` 让输出有换行，否则下一次输出会黏在一起。
- 想同时看耗时：`-w '%{http_code} %{time_total}\n'`。

</details>

### 挑战 25 · 查看本机到 `8.8.8.8` 走哪条路由、用哪个源地址

<details><summary>答案</summary>

```bash
$ ip route get 8.8.8.8
8.8.8.8 via 192.168.1.1 dev enp0s3 src 192.168.1.50 uid 1000
```

**要点**：
- `ip route get` 让内核**模拟一次真实的路由决策**，会考虑策略路由和多张路由表 —— 比读 `ip route` 更准确。
- `src` 就是"多网卡机器上到底用哪个 IP 出去"的答案。脚本里取出口网卡的可靠写法：
  ```bash
  $ ip route get 1.1.1.1 | awk '{for(i=1;i<=NF;i++) if($i=="dev") print $(i+1)}'
  ```
- `ip route get 192.168.1.60` 这种同子网的目标会**不带 `via`**（直连，走 ARP）。

</details>

## 附：这些命令的"常见错法"对照表

| 想做的事 | ❌ 常见错法 | ✅ 正确 |
|----------|-------------|---------|
| 找 3 天内改过的文件 | `find . -mtime 3` | `find . -mtime -3` |
| 找 SUID 文件 | `find / -perm 4000` | `find / -perm -4000` |
| 按数值排序 | `sort -k2` | `sort -k2,2n` |
| 按人类可读大小排序 | `sort -k1` | `sort -h` |
| 去重 | `uniq` | `sort \| uniq` |
| 排序写回原文件 | `sort f > f` | `sort -o f f` |
| 打印某几行 | `sed '5,10p' f` | `sed -n '5,10p' f` |
| 替换全部 | `sed 's/a/b/' f` | `sed 's/a/b/g' f` |
| 重定向走 sudo | `sudo echo x > /etc/f` | `echo x \| sudo tee /etc/f` |
| 同时重定向两个流 | `cmd 2>&1 > f` | `cmd > f 2>&1` |
| 处理含空格文件名 | `find . \| xargs cmd` | `find . -print0 \| xargs -0 cmd` |
| 看别人能不能连 | 只看 `ss -tlnp` | 看 `ss -tlnp` 的**监听地址**是不是 `0.0.0.0` |
| 看瞬时 CPU | `ps aux \| sort -k3 -rn` | `top -bn1 \| head` |
| 强杀卡住的进程 | `kill -9` 当第一手段 | 先 `kill`，再 `kill -9` |
| 用 root 跑整个管道 | 一串命令都加 `sudo` | 只给需要权限的那一步加 |
| 让变量对子进程可见 | `VAR=x cmd`（只对这条命令） | `export VAR=x` |
| 查 DNS | 只看 `dig` | `getent hosts`（走完整 nsswitch 链） |
| 数"总共出现几次" | `grep -c` | `grep -o \| wc -l` |
