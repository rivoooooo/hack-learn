# t50

> Multi-protocol packet injector tool Multi-protocol packet injector tool for *nix systems, actually supporting 15 protocols. Features: Flooding CIDR support

> **功能分类**：漏洞分析 ｜ **Kali 包**：`t50` ｜ **官方文档**：<https://www.kali.org/tools/t50/>

## 1. 安装

```bash
sudo apt update
sudo apt install t50
```
