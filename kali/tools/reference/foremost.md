# foremost

> Forensic program to recover lost files Foremost is a forensic program to recover lost files based on their headers, footers, and internal data structures. Foremost can work on image files, such as those generated by dd, Safeback, Encase, e…

> **功能分类**：数字取证 ｜ **Kali 包**：`foremost` ｜ **官方文档**：<https://www.kali.org/tools/foremost/>

## 4. 实践清单

按顺序做完这五步，就能把工具从「装上」推进到「会用」：

- [ ] **1.** **装好并确认版本** —— `sudo apt install foremost`，再执行 `foremost --version` 2>/dev/null || `foremost -V`
- [ ] **2.** **读官方帮助** —— `foremost -h`，需要细节时 `man foremost`
- [ ] **3.** **在自有靶场跑最小用例** —— 用 `foremost -h` 里最简单的那个子命令试一次
- [ ] **4.** **对照官方文档确认参数语义** —— <https://www.kali.org/tools/foremost/>，重点核对上一步用到的每个参数
- [ ] **5.** **记录输出并解读** —— 把关键字段抄进笔记，写清「它说明什么」「下一步该做什么」

> ⚠️ 只在**自己的设备**或**获得书面授权**的目标上使用。未授权扫描/入侵在多数司法辖区构成违法。
