# xplico

> Network Forensic Analysis Tool (NFAT) The goal of Xplico is extract from an internet traffic capture the applications data contained. For example, from a pcap file Xplico extracts each email (POP, IMAP, and SMTP protocols), all HTTP conten…

> **功能分类**：数字取证 ｜ **Kali 包**：`xplico` ｜ **官方文档**：<https://www.kali.org/tools/xplico/>

## 1. 安装

```bash
sudo apt update
sudo apt install xplico
```

## 4. 实践清单

按顺序做完这五步，就能把工具从「装上」推进到「会用」：

- [ ] **1.** **装好并确认版本** —— `sudo apt install xplico`，再执行 `xplico --version` 2>/dev/null || `xplico -V`
- [ ] **2.** **读官方帮助** —— `xplico -h`，需要细节时 `man xplico`
- [ ] **3.** **在自有靶场跑最小用例** —— 用 `xplico -h` 里最简单的那个子命令试一次
- [ ] **4.** **对照官方文档确认参数语义** —— <https://www.kali.org/tools/xplico/>，重点核对上一步用到的每个参数
- [ ] **5.** **记录输出并解读** —— 把关键字段抄进笔记，写清「它说明什么」「下一步该做什么」

> ⚠️ 只在**自己的设备**或**获得书面授权**的目标上使用。未授权扫描/入侵在多数司法辖区构成违法。
